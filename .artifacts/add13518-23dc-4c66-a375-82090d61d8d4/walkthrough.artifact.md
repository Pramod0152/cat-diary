# Walkthrough - Fixing Unresolved BuildConfig

The `Unresolved reference: BuildConfig` error in `PetWellApplication.kt` was caused by the `buildConfig` feature being disabled in the project's build configuration.

Starting with Android Gradle Plugin 8.0, the `BuildConfig` class is no longer generated by default to improve build speeds. Since this project references `BuildConfig.DEBUG` to conditionally apply database migrations, the feature needed to be explicitly enabled.

## Changes Made

### Build Configuration

#### [MODIFY] [app/build.gradle.kts](file:///C:/Learn/workspace/app/build.gradle.kts)

Enabled `buildConfig` within the `buildFeatures` block:

```kotlin
    buildFeatures {
        compose = true
        buildConfig = true // Added this line
    }
```
